# Phase 4 Habits

Apply from repository root:

```bash
python3 fitlife-phase-04-habits-patch/apply_phase_04.py
npm run build
npm run dev
```

Run `supabase/phase-04-habits.sql` once in Supabase SQL Editor.

The patch installs the left-date timeline CSS and focal-point component without replacing your current Log History or Sports media editor automatically. This protects the approved pages from accidental destructive replacement; those two components are ready to wire during the Phase 4 visual iteration.

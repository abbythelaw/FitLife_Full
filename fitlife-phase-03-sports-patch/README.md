# Phase 3 Sports patch

Apply from repository root:

```bash
python3 fitlife-phase-03-sports-patch/apply_phase_03.py
npm run build
npm run dev
```

Run `supabase/phase-03-sports.sql` once in Supabase SQL Editor. The patch includes grouped/backdated Log History building blocks. They are copied into the Log History feature and will be wired into its approved page during the Phase 3 iteration to avoid replacing any local Log History edits unexpectedly.
